Android App - Bluetooth Smart Home

Project for the Mobile Programming course (Networks and Telecommunications track), carried out in pairs on two physical Android smartphones lent by the school, with no emulator.

Goal

Make two Android smartphones exchange information over a Bluetooth connection in order to control a connected home.

How it works

  • A first screen lets the user choose a role: client (the remote control) or server (the hub).
  • Once the Bluetooth connection is established, the client lists the devices connected to the server's phone. Turning a device on or off sends a request over Bluetooth.
  • The server is a gateway between Bluetooth and a REST API (the smart home simulator). It forwards the action, then sends the updated state back to the client. It also shows a monitoring screen that refreshes periodically.

Technical aspects

  • Bluetooth RFCOMM sockets between two already paired phones: the server waits for a connection and the client connects using a shared UUID.
  • A dedicated thread reads and writes on the socket, and a Handler passes the received data to the main UI thread. The thread is shared between activities with a singleton.
  • Android components: Activities and Intents.

Deliverables

Commented code, a report of at most three pages describing the architecture and behaviour of the application, and a live demonstration.
