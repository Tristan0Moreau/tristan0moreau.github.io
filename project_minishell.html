Minishell - Unix Shell in C

Individual project for the Operating Systems course (Sciences du Numérique), developed in C during lab sessions.

Goal

Develop a simplified command interpreter offering the basic features of Unix shells such as bash.

How it works

  • The core is a loop that prints a prompt, reads a line from standard input and interprets it as a command, using a readcmd parsing module.
  • Each command is run by a child process, and the shell waits for its result before prompting again.
  • Built-in commands such as exit, which ends the loop, and cd are handled by the shell itself.

Scope of the assignment

The project is built step by step over the lab sessions: process management, signal handling, file redirections, pipes and multiplexing with select.
